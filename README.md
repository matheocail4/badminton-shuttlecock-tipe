# Impact du type de volants de badminton sur le jeu

TIPE — CAIL Mathéo (PSI) — Note finale : 18,6/20

## Sujet

Étude physique et numérique de la trajectoire "parachute" des volants de
badminton, comparant volant à plumes et volant en plastique (frottements,
oscillations, influence des matériaux).

## Contenu

- `Mcot_18398.pdf` — rapport
- `Présentation-TIPE-CAIL-Mathéo.pdf` — soutenance
- `TIPE_comparaison_CAIL_Mathéo.py` — script principal
- `Données_*.txt` — données de pointage (Tracker)

## Outils

Python (numpy, scipy, matplotlib), pointage vidéo Tracker, banc à air.
